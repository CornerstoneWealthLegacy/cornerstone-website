# Video Production Standards — QUALITY FIRST

**Directive (Arthur, 2026-06-07):** Don't ration credits. Spend what it takes to make
these *amazing*. This is a law firm's public face — premium footage builds trust;
cheap AI footage erodes it. On the 1,200-credit/mo plan we optimize for quality, not
credit-frugality.

## What this changes
- **Use the premium models for hero/motion shots**, not the budget ones:
  - **Seedance 2.0** (top-end motion, multi-shot, cinematic) — default hero video model.
  - **Google Veo 3.1** (full, not Lite) — for realistic, clean, physically-plausible motion.
  - **Kling 3.0** — premium alternative for dynamic camera moves.
  - Drop to Veo Lite / Seedance 1.5 only when a shot is simple and they already nail it.
- **Generate 2–3 takes of every hero shot and keep the best.** Budget for it — retries
  are expected, not waste. "Amazing" comes from selection, not first-try luck.
- **Stills stay on the unlimited models** (Nano Banana 2 / Seedream / Flux.2 Pro) — they're
  free and already excellent, so spend the credits on motion, not images.
- **Longer / more shots are fine** if they make the piece better (e.g., an extra establishing
  shot, a second camera angle, a satisfying closing beat).
- **Soul ID option:** for on-camera-style realism without filming, we can train a Soul
  Character later — but for the faceless pack we stay faceless + Arthur's VO.

## Quality bar (every video)
1. Crisp, intentional camera motion (push-in, parallax) — no drifting/warping AI mush.
2. Consistent brand grade: navy #1d2d4a, gold #b88a3e, warm light, shallow DOF.
3. No artifacts on hands, faces (none anyway), or readable text — regenerate if present.
4. Clean audio: Arthur's VO leveled, light noise reduction, music bed low under voice.
5. Burned-in captions proofread; disclaimer strip + end-card on every export.
6. Export high bitrate 1080×1920 (9:16); don't let the editor recompress to mush.

## Practical model ladder (per shot)
| Need | Model | Note |
|---|---|---|
| Hero cinematic motion | **Seedance 2.0** | default for the "wow" shots |
| Realistic real-world motion | **Veo 3.1 (full)** | trucks, homes, hands, documents |
| Dynamic camera/energy | **Kling 3.0** | when a shot needs movement |
| Simple/established look | Veo 3.1 Lite / Seedance 1.5 | only if it already looks great |
| All stills & graphics | Nano Banana 2 / Seedream / Flux.2 Pro | unlimited = free |

## Net effect on the lead-magnet batch
Earlier "lean" estimate was ~18–23 credits for all three. Quality-first (premium models +
2–3 takes per hero) is more like **~60–120 credits for all three, polished** — still
~5–10% of one month's allowance. Worth it.
