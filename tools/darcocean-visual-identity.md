# Darcocean — Visual Identity Spec (DRAFT)

The flat, scalable system (NOT the 3D chrome). Designer- and AI-ready. Contingent on final name.

## The mark
A **"D" monogram with a negative-space wave that doubles as an eye** — depth (ocean) + vision.
- **Flat / geometric**, single weight. No bevels, no 3D extrusion, no chrome, no heavy gradients.
- Must read at **16px** (favicon) and in **one color**. Test the wave at tiny size — if it muddies,
  simplify to a single clean wave curve.
- Three required forms: **D-only mark** (avatars/app icon/favicon), **stacked lockup** (mark above
  DARCOCEAN), **horizontal lockup** (mark beside DARCOCEAN).

## Color system (one mark, per-vertical accent)
- **Darcocean Navy** `#0E2A47` (primary — trust, depth)
- **Darcocean Gold** `#B88A3E` (law accent — premium)  ·  **Silver/Slate** `#9AA7B4` (secondary)
- **Ink** `#15161A`  ·  **Cloud** `#F5F7FB`  ·  white
- **Per vertical:**
  - **Darcocean Law** → Navy + Gold (trust/premium) ← primary brand
  - **Darcocean Real Estate** → Navy + Teal `#1FA6A6`
  - **Darcocean Capital** → Navy + deep Green `#1F6F4A`
  - **Darcocean Insurance** → Navy + Slate-Blue `#3E6CA6`
  (Same D-wave mark every time; only the accent shifts. That's what makes the empire feel unified.)

## Typography
- **Wordmark / headings:** a clean geometric or humanist sans (e.g., Montserrat, Poppins, or
  Söhne/Inter for web). Wide letter-spacing on "DARCOCEAN" (~0.12em).
- **Body / documents:** keep the legal docs in EB Garamond (already in use) for gravitas; UI in Inter.
- The locked wordmark **DARCOCEAN** is also the spelling fix — always show it set, never reword.

## Usage rules
- Clear space = height of the "D" on all sides. Min mark size 24px digital.
- Approved backgrounds: navy, white, cloud. Reverse (white mark) on navy. Mono (all-navy or all-white)
  for stamps, embroidery, fax, single-color print.
- **Don'ts:** no 3D/bevel/chrome, no drop shadows, no recoloring outside the palette, no stretching,
  no busy photo backgrounds behind the mark, no rewording the wordmark.
